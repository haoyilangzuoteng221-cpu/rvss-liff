# 外部向けAI分科会 参加申込（10/30・11/2を選べる。両日も可。押すのはボタン1つ）

10/21夜の鈴木琢仁さんMTGの決定（参加ボタン1つ・名前を書かない・押したら公式LINEで日時とZoom）で作り替え、10/22 15時に「10/30（講師ゆいなさん・22:00〜22:30）と11/2（講師永藤さん）を選べる、両日も可」へ変えた（Adness 087ec80f・89c053d0）。外部の学生が公式LINEの配信からこのページを開き、回のカードを選んで「参加する」（2回選ぶと「両日に参加する」）を押すだけ。選べる回が1つだけなら最初から選んである。名前・メール・大学学年の入力はなく、名前はLINEの表示名で記録する。押すと公式LINEから、申し込んだ回の日時とZoomリンクが1通にまとまって自動で届き、各回の当日12:00と開始1時間前に採用からリマインドが届く。前日20時の一斉リマインドは広報（鈴木さん）が送るので、ここでは送らない。

## どこを書き換えるか

回ごとの開始・終了時刻・Zoom・題・講師の表記は、専用GASの `人事採用/02_選考・フォロー/分科会受付GAS/開催設定.js` だけが持つ。この画面は日時を書かず、GASの応答をそのまま出す。時刻とZoomのどれかが空の回は申込ページに出さず、確認LINE・リマインドも送らない（仮の値を公開しない）。講師は対外に出してよい表記だけ（ゆいなさんは「ゆいな」「日本大学芸術学部」だけ）。

10/22 15時の版で、10/21案の見出し（勉強・レポートのChatGPT）と「21:00〜21:30」入りの画像を外した。配信画像ができたら、上に置くかを決める。

## 画面の分岐

- 一部の回に申込済み → その回は「申込済み」で選べず、残りの回だけ選べる
- 全部の回に申込済みで開き直す → 「お申し込み済みです」
- 公式LINEの友だちでない（`liff.getFriendship`）→ 送らずに、完了画面へ回ごとのZoomボタンと友だち追加ボタンを出す
- 確認LINEが送れなかった（上限・停止中など）→ 完了画面へ回ごとのZoomボタンを出す。押し直すと送り直す

確認用：`http://localhost:8731/bunkakai/entry/?preview=1`（`&case=registered`／`all`／`nofriend`／`failed`）。保存も送信もしない。

## 保存と既存機能の保護

専用ソースは `人事採用/02_選考・フォロー/分科会受付GAS/`。共有GASの全体反映は自動承認審査で拒否され実行せず、独立プロジェクトへ分離した。既存フォームの公開先・会員向け `/bunkakai/`・共有GASのトリガー・Lステップは変更しない。

受付は専用タブ「分科会申込_LIFF受」に1人・1開催を1行で保存し（両日なら2行）、同じ人の再送は同じ受付番号を返す。1〜15列は10/21版のまま（採用の集計＝共有GAS `申込計測_20260921.js` が5・7・8列を読む）。16〜18列に自動LINEの記録（確認LINE／当日昼LINE／1時間前LINE：送った日時か、送らなかった理由）を足した。LINEアクセストークンはサーバーでチャネルと期限を検証し、保存しない。候補者マスターへの名寄せ（LINE IDで照合・空欄だけ補完・初回申込施策と日付は76〜77列の空欄だけ）は10/21版と同じ。

採用の申込合計は候補者マスターの BX/BY を行で数える。メール無しの外部参加者も、専用GASが自分で BX/BY を書くので1人1行で入る（共有GASの `rvssApply_fill_` はメール無しの行を飛ばすが、書いた値は消さない）。⚠ 名寄せの並べ替え（列ズレ防止）はメール無しの行を氏名で追うため、表示名が同じ外部参加者が2人いると BX/BY が外れ、次に誰かが申し込んだときに受付タブから書き直されるまで数え漏れる。通し検証＝専用GASの `tests/集計の通し.cjs`（共有GASのファイルは読むだけ）。

旧版の `../../assets/bunkakai-entry.js`・`bunkakai-entry.css` はこのページから参照を外した（他のページは使っていない）。
