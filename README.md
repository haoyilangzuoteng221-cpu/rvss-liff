## 2. `?src=` の付け方（入口の種類を数え分ける）

**リンクの末尾に付けるだけ。**付いていなければ `unknown` として記録する（SNSへは寄せない）。

| 経路 | 付ける値 | 配る先 |
|---|---|---|
| SNS・公式LINEのリッチメニュー | `?src=sns` | 広報 |
| リファラル | `?src=referral` | 小林さん・紹介者 |
| 対面PJ | `?src=taimen` | 萬年さん → 藤原さん・佐々木さん |
| 企画イベント | `?src=kikaku_<イベント名>` | 企画部署（イベントごとにQRを刷る） |

⚠ **イベント名に空白・日本語を入れない。**`src` は英数字とハイフン・アンダースコアだけを通す（不正な値は `unknown` に倒れる）。
`kikaku_REAL DECISION` → ✕ ／ **`kikaku_real-decision` → ○**

⚠ **QRは `https://liff.line.me/<LIFF ID>?src=...` を変換して作る。**生の動画URLを渡さない。
渡すと3つ同時に壊れる——①視聴を検知できない ②userIDが取れず追いLINEが打てない ③経路が残らない。

## 3. 設計上、動かすと壊れるもの

| 何 | なぜ |
|---|---|
| **送信は隠しiframe + form POST。fetch にしない** | GASの `/exec` は CORS ヘッダを返さないので、fetch だと送れても結果を読めない。しかも `googleusercontent.com` へリダイレクトするため no-cors でも扱いが不安定 |
| **氏名・メール・userID を URL に載せない** | 個人情報。必ず POST の body で送る。`src` だけがクエリに乗ってよい |
| **`font-size: 16px` を下げない** | iOS は 16px 未満の入力欄をタップすると画面を勝手に拡大する |
| **LIFF SDK に `integrity` を付けない** | `static.line-scdn.net/liff/edge/2/sdk.js` は LINE が随時更新する版なので、ハッシュを固定すると更新日に全ページが白紙になる |
| **`rvssLx_` の接頭辞を外さない** | Apps Script は同名関数を後勝ちで**黙って**上書きする。2026-09-02 に `fin21_runAll` の衝突で育成側の関数が消えかけている |

### 使い方

### 2026-09-05 に見つけて直したバグ（同じ形を作らないために残す）

**LIFF ID が未設定のとき、画面が完全に真っ白になっていた。**

原因＝エラー文の出し先 `#status` が **`#form-area` の中**にあり、起動に失敗した時点ではその親ごと `hidden` だった。**書き込んではいるが、誰にも見えない。**

∴ **`#boot-status` を `#loading` の直後（どの hidden ブロックの外）に置き、起動時のエラーはそちらへ出す**ようにした（`RVSS.setBootStatus`）。

**★教訓＝「エラーを出す場所」が「エラーで隠れる場所」の中にあると、失敗が無音になる。**
新しく状態表示を足すときは、**失敗したときにその要素が見えるかどうか**を先に確かめる。
